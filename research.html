Projects

GNN for Grain Track

Notebook-driven graph neural network workflows for modelling grain-scale responses using both a demo TGNN dataset (Hu et al., 2024) and experimental grain neighbourhood measurements. Builds PyTorch Geometric graphs and evaluates predicted responses across strain increments.

GNN PyTorch Geometric Strain paths Experimental

Grain Track

Tools and data for tracking microstructural grains across deformation or processing steps. Provides a lightweight Python package for grain-map operations and tracking, plus scripts that merge per-step results and build directed lineage graphs for downstream analysis.

EBSD/DIC Microstructure Tracking Graphs
View repository

ML for XRD Quantitative Phase Analysis

Training and evaluation pipeline for quantitative phase analysis (QPA) from XRD intensity patterns. Models are trained on synthetic mixtures and benchmarked against the Madsen (2001) round-robin expert dataset for three-phase weight-fraction prediction.

XRD Regression Benchmark PyTorch
View repository

CPICANN Phase Classification

Training + validation workflows for crystal structure/phase classification from XRD using CNN, attention-only (ViT-style), and CPICANN hybrid architectures. Includes quick validation scripts and Monash M3 SLURM training pipelines.

XRD Classification CNN–Transformer HPC
View repository

XRD Space-Group Analysis

Deep-learning workspace for predicting crystallographic properties directly from simulated XRD spectra. Supports single-task space-group prediction and multi-task learning (space group, crystal system, Bravais lattice type, and elemental composition), with WANDB tracking and HPC helpers.

XRD Space groups Multitask WANDB

XRD Phase Analysis (Semester 2, 2025)

End-to-end tooling to synthesize multiphase XRD mixtures, train CNN regressors/multitask models to recover phase fractions, and analyze experiments locally or on HPC. Includes data generation scripts and documented failure modes + next-step improvements.
